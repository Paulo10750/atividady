Seno e Cosseno no Círculo Trigonométrico

Dado um arco trigonométrico AM de medida x, chamamos de:

Definições
cos x = abscissa de M
sen x = ordenada de M
Valores Notáveis

Como o raio da circunferência trigonométrica é unitário (medida = 1):

Cosseno cos 0° = 1 cos 90° = 0 cos 180° = -1 cos 270° = 0 cos 360° = 1
Seno sen 0° = 0 sen 90° = 1 sen 180° = 0 sen 270° = -1 sen 360° = 0

Exemplo

Calcule o valor da expressão:

E = (sen 180° + cos 180° - sen 270°) / (sen 90° + cos 360°)
sen 180° = 0 cos 180° = -1 sen 270° = -1 sen 90° = 1 cos 360° = 1
E = (0 + (-1) - (-1)) / (1 + 1) = 0 / 2 = 0
