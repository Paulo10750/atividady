Matemática Básica

Equações do 1º Grau com 1 Incógnita

O que é uma Equação?

Equação é uma sentença matemática aberta que exprime uma relação de igualdade.

Exemplos:
7x = 8
4k - 16 = 3c + 1
8x² - 256 = x + 200
Atenção:

Números em uma equação podem aparecer com operadores:

4 + 6 = 10
2a + b ≠ c → não é equação
14 - 28 < 10 → não é equação

Para ser uma equação, precisa de:

  • 1 Algo com valor desconhecido — chamado de incógnita ou variável.
  • 2 O sinal de igual (=).
Grau da Equação

O grau é definido pelo maior expoente da variável.

2 - x = 8 Grau 1
7x³ = 278 Grau 3
25x² - 3 = 0 Grau 2
x⁵ - x⁸ = 27 Grau 8

Obs: O expoente negativo não altera o grau.

Partes da Equação

Toda equação possui dois membros:

1º Membro
25x⁸ - 16x⁴ - 9x³
=
2º Membro
4x² - 1x + 1
Propriedade

Só se pode fazer uma operação de cada vez em ambos os lados para manter a igualdade.

50t + 20x = 400 + 50
20x + 50 = 450

Como Resolver

Forma geral: ax + b = 0, com a ≠ 0

Exemplo:
25 + 2x + 3x + 25 = 0
1º Passo:

Juntar todos os termos com variável em um lado e os números sem variável no outro.

25 + 2x + 3x + 25 = 0
5x + 50 = 0
2º Passo:

Colocar a variável e o termo independente em lados diferentes.

5x = -50
3º Passo:

Passar o coeficiente de "x" dividindo para o outro lado.

x = -50 / 5
4º Passo:

Resolver a operação e encontrar o resultado.

x = -10

Propriedade Distributiva

Conceito

Multiplicamos o termo de fora por todos os de dentro.

7x(4 + a) = 0
7x · 4 + 7x · a = 0
28x + 7ax = 0
